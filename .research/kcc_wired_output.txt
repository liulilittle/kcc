PART 5: TSO PARAMETERS -- Wired Fiber Exhaustive Analysis
================================================================================

  TSO (TCP Segmentation Offload) on wired fiber:
  Wired NICs support TSO/GRO with large segment counts (up to 127).
  No wireless A-MPDU aggregation -- burst is purely TSO-driven.
  At 10-100Gbps fiber speeds, even large bursts finish in microseconds.

     TSO segs   Burst(KB)       T@1G      T@10G     T@100G    Queue@1G   ACLscore
    ---------------------------------------------------------------------------
           45        63.6     0.51ms     0.05ms     0.01ms       0.51ms     0.0110
           64        90.5     0.72ms     0.07ms     0.01ms       0.72ms     0.0156
          127       179.6     1.44ms     0.14ms     0.01ms       1.44ms     0.0310

  Wired fiber TSO recommendations:
  +---------------------------------------------------------------------+
  | On wired fiber, TSO segments are delivered as a single NIC burst.  |
  | At 10Gbps+: 127 segs * 1448B = 179KB takes 143us -- negligible.    |
  | At 1Gbps:    127 segs * 1448B = 179KB takes 1.4ms -- manageable.   |
  |                                                                     |
  | For 10-100Gbps DC: 127 is optimal (max throughput, us burst)       |
  | For 1Gbps WAN fiber: 64 is safe (0.7ms burst << RTT)               |
  | For ultra-low-RTT DC (<0.5ms): 45 prevents self-queue in same RTT  |
  +---------------------------------------------------------------------+

PART 6: min_rtt STICKY RATIO -- Wired Fiber Exhaustive Analysis
================================================================================

  min_rtt sticky mechanism:
    if new_rtt < min_rtt * num/den:
        min_rtt reduces by num/den per sample
    else:
        min_rtt stays

  On wired fiber, transient RTT dips are extremely rare because:
    - No CSMA backoff (unlike WiFi)
    - No L2 retransmission bursts (unlike WiFi/cellular)
    - Switch buffers drain deterministically (DCTCP ECN marks)
    - Physical path is fixed (fiber doesn't move)

  Tradeoff:
    Higher sticky ratio (87/100 or 95/100): very resistant to noise
    Lower sticky ratio (75/100): faster min_rtt convergence on cold start
